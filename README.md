# The Last War

**A cinematic, interactive work of science fiction about autonomous warfare, artificial intelligence, and the price of perfect peace.**

### [▶ Read The Last War — Launch the Interactive Website](https://thefirstbluegoose.github.io/The-Last-War/)

Experience the story online: **https://thefirstbluegoose.github.io/The-Last-War/**

The story explores a future in which military competition shifts from human armies to autonomous drone networks and AI systems. The pursuit of flawless security leads to an unsettling question: who gets to decide what peace means?

## About this site

This repository hosts the interactive HTML edition of *The Last War*. The website features cinematic typography, illustrated environments, story chapters, and interactive visualizations.

## View locally

Download `index.html` and open it in a modern web browser. The site is also published through GitHub Pages using the `main` branch.
